# Аптека

Учебное WPF-приложение для работы с каталогом лекарственных препаратов и оформления продаж в аптеке. Программа позволяет сотрудникам находить препараты, добавлять их в корзину и сохранять продажи в базе данных MS SQL Server. Администратор дополнительно может добавлять, редактировать и удалять препараты.

Проект выполнен на C# в Visual Studio 2022 с использованием WPF (.NET Framework 4.8) и Entity Framework 6 (ADO.NET Entity Data Model, Database First).

## Визуальная демонстрация

Главное окно программы предназначено для авторизации. После входа открывается каталог, в котором препараты отображаются в виде карточек с названием, описанием, ценой, производителем и категорией. Справа расположена корзина. Отдельное окно показывает историю продаж.

Скриншоты интерфейса при необходимости можно добавить в этот раздел после запуска приложения.

## Установка

Для запуска необходимы Visual Studio 2022 с поддержкой WPF (.NET Framework), .NET Framework 4.8, SQL Server и пакет EntityFramework 6.

Откройте решение "Apteka.sln" в Visual Studio. Убедитесь, что база данных "Apteka" существует на вашем SQL Server. Если подключение ещё не настроено, добавьте в папку "Entity" модель ADO.NET Entity Data Model "AptekaModel.edmx", выберите **EF Designer from database** и подключите семь таблиц базы данных.

Проверьте строку подключения в "App.config" и при необходимости укажите свой сервер. Затем соберите проект через "Ctrl + Shift + B" и запустите клавишей "F5".

## Использование

При запуске откроется окно входа. Введите логин и пароль существующего пользователя либо зарегистрируйте нового сотрудника.

В каталоге можно найти препарат по названию, посмотреть его описание, цену, производителя и категорию. Кнопка «В корзину» добавляет выбранный препарат; после нажатия «Оформить продажу» данные сохраняются в таблице "Prodazhi". В окне «Продажи» можно просмотреть историю оформленных операций без возможности редактирования или удаления.

Администратору доступны дополнительные кнопки добавления, изменения и удаления препаратов. Сотрудник может просматривать каталог, пользоваться корзиной и оформлять продажи.

## Данные

Приложение использует базу данных "Apteka" в MS SQL Server. Она содержит семь таблиц: "Preparaty" (препараты), "Proizvoditeli" (производители), "Kategorii" (категории), "Sotrudniki" (сотрудники), "Prodazhi" (продажи), "Users" (учётные записи) и "Roles" (роли).

У каждой продажи сохраняются препарат, сотрудник, дата, количество и цена за единицу. Общая сумма рассчитывается по количеству и цене. Для оформления продажи учётная запись должна быть связана с сотрудником через поле "Sotrudniki.IdUser".

В приложении используются две роли: администратор ("IdRole = 1") и сотрудник ("IdRole = 2").
